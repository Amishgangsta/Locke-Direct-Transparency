## Reporting route

The repository does not currently publish a dedicated private security-reporting inbox. For non-sensitive observations, open a GitHub issue in this repository. For account, payment, privacy, security, or other sensitive matters, contact **support@lockedirect.com** rather than placing details in a public issue.

Do not publish exploitable security details, credentials, customer information, private URLs containing capabilities, or proof-of-concept attacks in a public issue. Include only the minimum reproducible description needed for triage, and redact personal data.

No separate safe-harbor commitment is represented here because one has not been adopted as a public policy. This document describes a reporting route, not a promise about legal treatment or response time.
